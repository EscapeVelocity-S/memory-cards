# 记忆卡片

一个纯前端、无需安装的记忆卡片小程序，手机和电脑浏览器均可使用。

## 本地使用

双击 `打开记忆卡片.bat`，或直接双击 `index.html`。应用会在默认浏览器中打开。

## 发布并分享链接

项目只包含静态文件，不需要后端服务。将整个文件夹部署到任意静态网站托管平台即可获得可分享链接，例如：

- GitHub Pages：把文件上传到 GitHub 仓库，在仓库 Settings → Pages 中启用发布；
- Netlify Drop：将整个文件夹拖到 Netlify Drop 页面；
- Vercel：导入包含这些文件的仓库，使用默认静态站点配置发布。

不要把本机的 `file:///.../index.html` 地址发给朋友，这个地址只在自己的电脑上有效。

## 数据说明

卡组和卡片保存在当前浏览器的 `localStorage` 中。刷新或关闭网页后数据仍会保留；不同设备、浏览器或网站地址之间的数据彼此独立。清理浏览器的站点数据会同时清除卡片数据。
